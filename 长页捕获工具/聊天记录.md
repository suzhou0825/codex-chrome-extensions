# 聊天记录

## 2026-06-11 版本 1.0.2

- 用户反馈 PDF 截图完成后合并时报错：`Failed to execute 'atob' on 'Window': The string to be decoded is not correctly encoded.`。
- 判断原因为 PDF 数据转 base64 时分块大小不是 3 的倍数，导致拼接后的 base64 非法。
- 修正 base64 分块编码大小，升级版本号到 `1.0.2`，同步更新插件清单和更新说明。

## 2026-06-11 版本 1.0.1

- 用户反馈选择 PDF 开始自动滚动时，报错 `This request exceeds the MAX_CAPTURE_VISIBLE_TAB_CALLS_PER_SECOND quota.`。
- 判断原因为 Chrome `captureVisibleTab` 截图接口调用过快。
- 增加截图接口最小调用间隔，避免超过每秒调用限制。
- 升级版本号到 `1.0.1`，同步更新插件清单和更新说明。

## 2026-06-11 版本 1.0.0

- 用户要求生成新的浏览器插件，点击后可实现网页长截图或保存 PDF。
- 用户要求插件自动下滑截图，最后合成一张长图；页面非常长时可保存为几张图片。
- 用户要求选择 PDF 时同样自动下滑，并生成多页合一的 PDF 文档。
- 用户要求图片和文档默认保存到下载文件夹。
- 按项目规则创建独立插件文件夹 `长页捕获工具`。
- 生成 popup 操作界面、后台截图脚本和页面合成脚本。
- 合成后的图片和 PDF 由页面脚本直接触发浏览器下载，避免超长页面生成的大文件经过后台消息传输。
