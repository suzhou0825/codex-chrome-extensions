# 长页捕获工具

Chrome / Edge 浏览器插件，用于自动滚动当前网页，并保存为长截图或多页 PDF。

## 安装

1. 打开 `chrome://extensions/`
2. 开启右上角“开发者模式”
3. 点击“加载已解压的扩展程序”
4. 选择本目录：`/Users/donysu/Documents/Codex/浏览器插件库/长页捕获工具`

## 使用

1. 打开需要保存的网页。
2. 点击浏览器工具栏里的插件图标。
3. 选择“长截图 PNG”或“多页 PDF”。
4. 点击“开始捕获”。

## 说明

- 文件默认保存到浏览器下载文件夹。
- 长截图过高时会自动拆分为多张 PNG。
- PDF 会按滚动截图顺序生成多页文档。
- 浏览器内部页面，例如 `chrome://extensions/`，不支持截图。
