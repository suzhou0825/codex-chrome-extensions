# 更新说明

## 1.0.6

- 放宽今日头条 `tplv-tt-post` 图片过滤规则。
- 不再因为图片宽度小于 700 像素就跳过，避免误删正文竖图。
- 仅过滤小方图和横版卡片缩略图。

## 1.0.5

- 调整今日头条 `tplv-tt-post` 过滤策略。
- 不再一律跳过 `tplv-tt-post`，改为只过滤小尺寸或横版卡片缩略图，保留较大的正文图。

## 1.0.4

- 针对今日头条页面增加 `tplv-tt-post` 推荐缩略图过滤。
- 减少正文下方推荐内容、热榜内容缩略图误采。

## 1.0.3

- 增加新闻/文章卡片链接过滤。
- 图片位于跳转到其他文章的链接卡片中时跳过，减少推荐文章封面误采。

## 1.0.2

- 正文根容器只保留最高评分区域，减少外层大容器误采。
- 增加附录、相关阅读、推荐阅读、参考资料、声明、评论等分隔标记后的图片过滤。
- 增加 appendix、annex、reference 等附录/参考区域类名和 ID 过滤。

## 1.0.1

- 采集范围改为优先扫描正文、文章、主内容区域。
- 增加导航、侧栏、推荐新闻、广告、评论、图标、头像等排除规则。
- 默认最小图片宽度调整为 300 像素，减少图标和小缩略图误采。

## 1.0.0

- 新增当前网页图片采集功能。
- 优先尝试获取原图地址，包括图片链接、懒加载属性和 `srcset` 最大图。
- 支持采集 CSS 背景图。
- 图片默认保存到下载文件夹下的 `网页图片` 子文件夹。
