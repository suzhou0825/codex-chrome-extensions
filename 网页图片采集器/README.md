# 网页图片采集器

Chrome / Edge 浏览器插件，用于提取当前网页图片，并保存到下载文件夹。

## 安装

1. 打开 `chrome://extensions/`
2. 开启右上角“开发者模式”
3. 点击“加载已解压的扩展程序”
4. 选择本目录：`/Users/donysu/Documents/Codex/浏览器插件库/网页图片采集器`

## 使用

1. 打开需要采集图片的网页。
2. 点击浏览器工具栏里的插件图标。
3. 选择是否包含背景图、最小图片宽度。
4. 点击“开始保存图片”。

## 说明

- 图片默认保存到下载文件夹下的 `网页图片` 子文件夹。
- 每次采集会按网页标题和时间生成独立子文件夹。
- 默认优先扫描正文、文章、主内容区域，尽量避开导航、侧栏、推荐新闻、广告、评论等区域。
- 遇到附录、相关阅读、推荐阅读、参考资料、声明、评论等标记后的图片会跳过。
- 图片位于跳转到其他文章/新闻的卡片链接中时会跳过，避免采集推荐文章封面。
- 对今日头条页面会按尺寸过滤 `tplv-tt-post` 小方图和横版卡片缩略图，保留正文竖图和大图。
- 会优先尝试链接原图、懒加载原图属性、`srcset` 最大图，再回退到当前显示图片。
- 浏览器内部页面，例如 `chrome://extensions/`，不支持采集。
