# 聊天记录

## 2026-06-11 版本 1.0.0

- 用户需要为 Discuz 模板论坛制作浏览器插件，在目录页无需打开详情页即可看到帖子首图。
- 确认示例页面为 GBK 编码，目录页没有首图字段，需要请求详情页解析楼主正文首图。
- 生成独立插件文件夹 `网站深扫插件`，实现目录页首图展示、并发限制和 7 天缓存。

## 2026-06-11 版本 1.0.1

- 用户要求插件名中性，不能用示例网站命名。
- 插件名改为 `网站深扫插件`。
- 用户要求点击目录页详情链接时，不直接打开标签页，而是用弹窗展示详情页。
- 新增详情页弹窗阅读功能，保留 Ctrl / Cmd 点击和中键点击的新标签行为。
- 用户要求弹窗尺寸缩小。
- 桌面端弹窗改为居中阅读窗口，最大尺寸 `1180x820`。
- 用户要求根目录生成插件清单，记录插件名和最新版本号。
- 新增根目录 `插件清单.md`。

## 2026-06-11 版本 1.0.2

- 用户要求将插件建设规则记录到项目根目录，包括版本号等要求。
- 用户要求每个插件文件夹下同步备份聊天记录，新版本生成时追加到同一个文件，不覆盖、不新建多个聊天记录文件。
- 用户强调不同浏览器插件聊天记录不能混淆。
- 新增根目录 `插件建设规则.md`。
- 新增本插件独立 `聊天记录.md`。
- 升级版本号到 `1.0.2`，并同步更新 `插件清单.md` 与 `更新说明.md`。
