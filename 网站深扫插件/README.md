# 网站深扫插件

Chrome / Edge 浏览器插件，用于在 Discuz 目录页直接显示帖子首图，并用弹窗打开详情页。

## 安装

1. 打开 `chrome://extensions/`
2. 开启右上角“开发者模式”
3. 点击“加载已解压的扩展程序”
4. 选择本目录：`/Users/donysu/Documents/Codex/浏览器插件库`

## 说明

- 插件只在福缘论坛页面运行。
- 首次打开目录页会逐条请求帖子详情页解析首图。
- 图片结果会缓存 7 天，后续打开同一帖子不重复抓取。
- 当前限制每页最多处理 50 条，并发 3 个请求，避免一次性请求过多。
- 点击目录页帖子标题或首图会弹出详情页；Ctrl / Cmd 点击、中键点击仍保留浏览器默认新标签行为。
